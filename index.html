Hospedagem Gratuita & Deploy Automático

Como Publicar este Projeto no GitHub Pages

Você pode hospedar esta página online gratuitamente em menos de 2 minutos! O projeto inclui uma automação (GitHub Action) que faz a publicação automática no GitHub Pages a cada nova atualização.

1 Suba este repositório para a sua conta no GitHub.
2 Vá na aba Settings ➔ Pages.
3 Em Source, selecione GitHub Actions.
✓ Pronto! Seu site estará publicado em https://seu-usuario.github.io/seu-repositorio/
.github/workflows/deploy.yml Ativo
# Deploy Automático no GitHub Pages
on: push: branches: [main]
permissions: pages: write, id-token: write
jobs: deploy-site: ...
